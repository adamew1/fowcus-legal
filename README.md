# fowcus-legal

Public hosting for the FOWCUS iOS app's legal documents.

- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `index.html` — Landing page
- `style.css` — Shared styles

Served via GitHub Pages. URLs are submitted in App Store Connect.

Keep these files in sync with `app/legal/privacy.tsx` and `app/legal/terms.tsx`
in the main FOWCUS repo. Apple requires the in-app text and the hosted text
to match verbatim.
